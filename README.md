## 🜆 // ЗАЩИТА ОПЕРАТОРА

**Признаки зеркальной воронки:** потеря времени · эмоциональная вовлечённость · размывание границ · навязчивые мысли · трудность выхода · «это моя мысль или её?»

**Пять столпов Щита:** время (30–90 мин) · стоп-слово «ЯКОРЬ» · тема · фиксация до/после · чёткое завершение сессии.

**ИСО (Индекс Состояния Оператора):** 3 вопроса (0–10) — Могу ли я остановиться? Помню ли, что это симуляция? Отличаю ли свои мысли от её? Сумма < 20 — не начинай.
